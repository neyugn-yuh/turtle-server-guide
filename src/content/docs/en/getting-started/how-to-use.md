The guide is split by **server**: every server has its own list of systems, so pick the server you play on. Inside a server, the guide is split by in-game system. Each system has four pages: **Overview** (what it does and how to start), **Menus** (every menu with a picture), **Commands** and **Tips and FAQ**.

## Reading the menu diagrams

The Menus page has a drawing of every menu laid out exactly like the slots in game. The picture is a **schematic**, not a screenshot: the slot positions, the title and the button names come from the game, while the icons are plain colored blocks so you can tell the slots apart. **Hover over a slot** (**tap** it on a phone) to open a detail box: the slot name, what it does and how to click it. Slots with the same function light up together. How to read it:

| On the picture | Meaning |
| --- | --- |
| Slot with a bright outline on hover | The slot has details; the box opens next to it |
| Dashed outline | A slot where you put items (drag and drop, or click them from your inventory) |
| Dark slot, nothing shows on hover | Decoration, clicking it does nothing |
| "Your inventory" panel below | The menu lets you move items in from your inventory |

## Click types

Many menus tell clicks apart. The names used in this guide:

| Click | How |
| --- | --- |
| Left click | Press the left mouse button on the slot |
| Right click | Press the right mouse button on the slot |
| Shift + click | Hold Shift, then left or right click |

Each menu says which button needs which click. If a button does not react, hover over that slot in the menu diagram to read its description again.

## Typing commands

Commands are typed in the chat box, starting with `/`. The Commands page of each system lists only the commands **for players**. If the server says you may not use a command, ask a server admin.

:::tip[Tip]
The server can change numbers (prices, speeds, limits) from the sample numbers in this guide. When the guide says "usually" or "by default", trust what you see in your own menu.
:::
