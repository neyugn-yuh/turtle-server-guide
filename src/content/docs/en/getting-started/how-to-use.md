The guide is split by in-game system. Each system has four pages: **Overview** (what it does and how to start), **Menus** (every menu with a picture), **Commands** and **Tips and FAQ**.

## Reading the menu diagrams

The Menus page has a drawing of every menu laid out exactly like the plugin's slots. The picture is a **schematic**, not a screenshot: the slot positions, the title and the button names come from the plugin, while the icons are plain colored blocks so you can tell the slots apart. How to read it:

| On the picture | Meaning |
| --- | --- |
| Green circle with a number | That slot has the row with the same number in the table right under the picture, saying what the button does |
| Dashed outline | A slot where you put items (drag and drop, or click them from your inventory) |
| Dark slot without a number | Decoration, clicking it does nothing |
| "Your inventory" panel below | The menu lets you move items in from your inventory |

## Click types

Many menus tell clicks apart. The names used in this guide:

| Click | How |
| --- | --- |
| Left click | Press the left mouse button on the slot |
| Right click | Press the right mouse button on the slot |
| Shift + click | Hold Shift, then left or right click |

Each menu says which button needs which click. If a button does not react, read its description in that menu's table again.

## Typing commands

Commands are typed in the chat box, starting with `/`. The Commands page of each system lists only the commands **for players**. If the server says you may not use a command, ask a server admin.

:::tip[Tip]
The server can change numbers (prices, speeds, limits) from the sample numbers in this guide. When the guide says "usually" or "by default", trust what you see in your own menu.
:::
