Each system works on its own, but they are made to connect. The table shows the main links. Some links exist only when the server runs the matching plugins.

| System | What you do | Connects to |
| --- | --- | --- |
| [Harvester hoes](/en/guides/turtle-hoes/overview/) | Break crops in the farm zones for produce, Essence and progress, then upgrade the hoe | Produce can go straight into the Backpack if the server runs TurtleBackpack |
| [Backpack](/en/guides/turtle-backpack/overview/) | Look at the virtual storage by type, withdraw, sell, turn on auto-sell, raise the capacity | Receives items from tools such as the harvester hoe |
| [Farm pets](/en/guides/turtle-farm-pets/overview/) | Raise pets that boost your stats and shoot the monsters that appear while you farm | Works while you farm with the server's harvester hoe or axe |
| [Land claims](/en/guides/turtle-lands/overview/) | Claim chunks, invite members, assign roles, set flags, use the land bank | Independent of the other systems |
| [Minions](/en/guides/turtle-minions/overview/) | Place minions on your island so they produce, even while you are offline | Needs your island; the number of minions you can place is counted per island |

## Which order to read them in

1. New to farming: **Harvester hoes**, then **Backpack** to learn where what you collect goes and how to sell it.
2. Once you farm regularly: **Farm pets** to be more efficient, **Minions** to earn while offline.
3. When you want to protect your area or play with friends: **Land claims**.

:::note[Your server may differ]
Server admins turn systems on or off and change their numbers. If a menu or command in the guide is not in your game, ask an admin whether the server uses that system.
:::
