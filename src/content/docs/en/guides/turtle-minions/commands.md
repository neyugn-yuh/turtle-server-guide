## Are there player commands?

The default version has no commands for ordinary players. You control minions through items and menus. You do not need a command to open a menu, collect products or pick up a minion.

| What you want to do | Control used instead of a command | Example |
| --- | --- | --- |
| Place a minion | Hold a minion item and right-click a block on your island | Place Cobblestone Minion I on a block's top face |
| Open its menu | Right-click the minion | View storage and fuel |
| Collect products | Click a product or `Collect all` | Collect all stored cobblestone |
| Open attached storage | Right-click the attached Minion Storage block | Collect products from Small Storage |
| Increase its tier | Click `Upgrade minion`, then confirm if the menu opens | View requirements for the next tier |
| Pick it up | Click `Pickup minion` or attack the minion | Pick it up to place elsewhere |

## When an action fails

| Symptom | What should you do? |
| --- | --- |
| Placement outside an island is refused | Return to your island and choose somewhere you can build |
| The island has no placement slots left | Pick up a minion or unlock more slots through methods your server allows |
| There is already a minion at that location | Choose another location |
| You cannot open another member's minion | Only the owner can open it by default; ask an administrator about shared access |
| You receive a permission error | Ask an administrator whether your server allows you to perform that action |
| Increasing the tier reports an unconfigured cost | Ask an administrator; no upgrade costs are provided by default |

If your server adds its own commands through other features, follow the server's instructions for those commands.
